Calls and registers cost less, so programs run 3% to 37% fewer machine instructions and print what they did. A recursion may use 32 GiB of stack, and past that, or when the system has no more memory to give, the run stops with "the program ran out of stack", where it used to run on until the system killed it. `internal::stack_depth` takes longer the deeper it is asked. `scarlet dis --instrs` numbers registers from `r2`, and it and `scarlet run --counters` have new names for calls and returns.
