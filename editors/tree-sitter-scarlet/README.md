# tree-sitter-scarlet

The tree-sitter grammar for Scarlet. Zed builds it from this directory. The
editor queries live in `editors/zed/languages/scarlet/`.

## Layout

- `grammar.js` — the structural rules, transcribed from the reference parser
  in `crates/scarlet_syntax/src/parser`.
- `lexical.js` — generated. `cargo xtask gen-editor-syntax` emits it from the
  compiler's token tables. Do not edit it.
- `src/scanner.c` — the external scanner. It produces one token: a `-` at the
  start of a line. The LR grammar cannot express that rule.
- `src/parser.c`, `src/grammar.json`, `src/node-types.json` — generated by
  `tree-sitter generate`. Grammar consumers build from these files. They are
  committed.

## Development

```sh
bun install
bun run generate
bun run corpus
```

`bun run generate` rebuilds `src/` after a change to `grammar.js`. `bun run
corpus` parses every `.sca` file in the repository and fails on any error
node. CI runs both. `cargo test -p xtask` fails while `lexical.js` or the
tmLanguage is stale. The grammar tracks the compiler or the build fails.
